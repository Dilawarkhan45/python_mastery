# Python Mastery

A collection of Python practice scripts covering fundamentals, functions, files, modules, OOP, and testing.

Run a script from the project folder with `python module_7.py`. Run tests with `python -m pytest`.

## Files

### Practice scripts
- `variables.py` - Input/output, data types, a student card, shop bill, and unit conversions.
- `conditions.py` - Number checks, a grade calculator, and an electricity bill.
- `loops.py` - Times tables, PIN attempts, and a number guessing game.
- `module_1.py` - Examples of collections and a class result sheet.
- `module_2.py` - Functions, grade reports, and comprehensions.
- `module_3.py` - List references, default arguments, and shallow/deep copying.
- `module_4.py` - Iterators, generators, file reading, and decorators.
- `module_5.py` - Safe division, a diary menu, and saving student results.
- `module_6.py` - Standard library examples and the school project exercises.
- `module_7.py` - Classes and objects: students, bank accounts, and a library.
- `module_8.py` - Type hints, a product dataclass, and JSON loading/saving.
- `module_9.py` - A debugging exercise for filtering and averaging passing marks.
- `bank_account.py` - Bank account class with deposit, withdrawal, and transaction history.
- `grades.py` - Grade calculation with marks-range validation.

### Tests
- `test_bank_account.py` - Tests bank account transactions and invalid operations.
- `test_grades.py` - Tests grade boundaries and invalid marks.

### Data and generated files
- `diary.txt` - Example diary entry used by the diary exercise.
- `logs.txt` - Sample log data used to demonstrate filtering error lines.
- `products.json` - Product records saved by the dataclass exercise.
- `results.csv` - Student marks, averages, and topper saved by the file-handling exercise.
- `results.json` - Student result records saved as JSON.

### Example projects
- `school_project/main.py` - Runs sample student reports and helper functions.
- `school_project/school_tools.py` - Reusable grade, report, circle-area, and even-number functions.
- `school_app/main.py` - Displays a sample student result, attendance, and student information.
- `school_app/school/__init__.py` - Exposes the school package's public helper functions.
- `school_app/school/attendance.py` - Calculates attendance percentages.
- `school_app/school/grades.py` - Calculates mark averages and grades.
- `school_app/school/student.py` - Formats student information.
- `school_app/requirements.txt` - Dependency list for the school app (currently empty).
- `school_app/.gitignore` - Git ignore configuration for the school app (currently empty).
